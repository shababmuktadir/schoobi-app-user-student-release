# Schoobi website
Static bilingual English/Bengali website for GitHub Pages. No Node.js or build step is required.
Pages: Home, About, Features, Pricing, Privacy, Terms, Subscription, Refund, Cancellation, Data Deletion, Security, Contact and FAQ.
Before publication verify the Google Apps Script endpoint, actual SDK/data collection, in-app account deletion, child target audience/Families requirements, billing rules and legal terms. The deletion form prepares an email; it does not delete backend records.
